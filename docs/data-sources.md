# 把自己的表格接成岗位来源

你有一张校招信息表（自己整理的、同学共享的、社群里流传的），想让 Zhiro 每天自动读它。不用写代码，三步。

## 三步

1. 打开 Zhiro，点**左下角的齿轮**进「配置」，滑到页面**最下面**的「岗位订阅」，点 **＋ 添加**。（页面上方的「模型服务」等不用管。）
2. 把表格的链接贴进去，点 **预览**。你会看到：
   - 它认出这是哪种表；
   - 每一项信息（公司、岗位、截止时间…）读的是表里的哪一列。认错了就在下拉框里改，改完下面的结果会自己刷新；
   - 这张表能读出多少个岗位，以及前 3 条的样子。
3. 起个名字，点 **确认接入**。等几秒（大表要一两分钟），「岗位订阅」里会多出这一行，上面写着「已接入…读到 N 条，其中新岗位 M 个」。之后每天自动更新一次。

读到的「条」是表里拆出来的岗位条数；「新岗位」是其中库里以前没有的。同一家公司里重名的岗位只算一个，所以后者可能少一点。

也可以直接对助手（或你自己的 agent）说：「把这张表接进来：<链接>」。

## 支持哪些表

| 表 | 链接怎么拿 |
|---|---|
| **飞书多维表格** | 打开表格 → 右上角「分享」→ 把「链接分享」设为 **互联网上获得链接的人可阅读** → 复制链接。链接里要有 `/base/` 和 `table=`。 |
| **CSV 链接** | 任何打开就是 CSV 内容的网址，以 `.csv` 结尾或带 `output=csv`。例如 Google 表格：文件 → 共享 → 发布到网络 → 选工作表和「逗号分隔值 (.csv)」→ 复制链接。GitHub 上的 CSV 文件用它的 Raw 链接。 |
| **电脑上的 CSV 文件** | 填文件的完整路径，如 `D:\…\岗位.csv`（Windows）或 `~/校招/岗位.csv`。Excel、WPS、腾讯文档都能「另存为 / 导出为 CSV」。之后你改了这个文件，Zhiro 下次更新时会读到。 |
| 腾讯文档、Notion、Excel 文件（.xlsx） | 目前不能直接接。导出为 CSV，按上一行接入。 |

## 表格要长什么样

第一行是列名，往下每行一家公司的一次招聘。**只有「公司」这一列是必需的**，其余有就读、没有就空着：

| 信息 | 常见的列名（这些都能自动认出） |
|---|---|
| 公司（必需） | 公司、企业名称、单位名称、用人单位 |
| 岗位 | 岗位、招聘岗位、职位。一格里写多个岗位时用顿号、逗号、分号隔开，会拆成多个岗位；中文内容里的空格也算分隔，英文内容里的空格不算（`Software Engineer` 是一个岗位） |
| 截止时间 | 截止时间、截止日期、网申截止、ddl。写日期（`2026-10-31`、`10月31日`）或「招满为止」 |
| 投递链接 | 投递链接、网申链接、网申地址 |
| 公告链接 | 公告链接、原文链接 |
| 工作地点 | 工作地点、城市。多个城市的写法同上 |
| 学历、专业 | 学历要求、专业要求 |
| 届次、批次 | 招聘届次、届次；批次、招聘批次 |
| 企业类型、行业、信息来源 | 企业类型、行业类别、公告来源 |

列名不在上面也没关系，预览时在下拉框里指给它就行。

## 接入以后

- **每天自动更新一次。** 想马上更新，在「岗位订阅」里点那一行的「立即更新」。
- **表里删掉的行**，对应的岗位会标为已关闭。你关注过或申请过的岗位不会被关。
- **截止时间已过的行**不会读进来。
- **表格里的信息不算官方来源。** 即使表里写着「来源：官网」，表里的截止日期也会显示成「仅来自汇总表：某月某日截止，待核实」；表里没写截止的显示「截止未核实」。
- **不想要了**：点那一行的「删除」，再点一次「确认删除」。它带来的岗位会一起清掉，你关注过或申请过的保留。
- **订阅存在 `config\jobos.yaml` 的 `sources:` 里，跟着备份走。** 每次备份（设置页「备份」或 `zhiro vault backup`）在 `backups\` 里放两份同名文件：`jobos-<时间>.db` 是数据库，`jobos-<时间>.yaml` 是那一刻的 `jobos.yaml`（密钥、飞书机器人地址已去掉）。订阅丢了的话，先停 Zhiro，把那份 `.yaml` 里整段 `sources:` 复制回 `config\jobos.yaml`，再启动。不会自动恢复。

## 读不出来时

| 提示 | 怎么办 |
|---|---|
| 这张表没有开「互联网上获得链接的人可阅读」 | 回飞书把链接分享打开；或者表的主人已经关了分享 |
| 没认出哪一列是公司 | 在预览里给「公司」选对应的列 |
| 没有一行能成岗位 | 公司列是空的、所有行都过了截止、或者填了「只要哪一届」而表里没有那一届 |
| 这个链接打开的是网页而不是 CSV | 用的是表格的普通网址，不是导出 / 发布链接；或者要登录才能看 |
| 这个链接打不开（HTTP 404 之类） | 链接不完整或已经失效。在浏览器里打开它试试，能直接看到或下载 CSV 内容才对 |
| 找不到这个文件 | 路径写错了，或者文件被移走了 |
| 还认不出这个链接是哪种招聘站或表格 | 贴的是普通网页，或者是还不支持的表格。表格请导出为 CSV 再接；单个招聘公告的网页不在这里接，用「找岗位」页里的粘贴链接抓取 |
| 只读公网上的链接 | 链接指向的是本机或内网地址。文件在自己电脑上就直接填路径 |

连续读不成不会停：Zhiro 会一直按周期重试，「岗位订阅」里能看到上次失败的原因。

## 给开发者

- 不开界面也能用：`zhiro data add <链接或文件> --name 名字`，`zhiro data list`，`zhiro data sync`，`zhiro data watch`（常驻）；`zhiro data probe <链接>` 只看读出来是什么、不写库。daemon 在跑的时候这些写入命令会拒绝执行，改用工具 `source.preview` / `source.add` / `source.remove` / `scan.run`。
- 想支持一种新的表格或招聘站：见 `apps/daemon/src/data/readers/README.md`。
