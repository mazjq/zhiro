# 在 Zhiro 窗口里用你自己的 Claude Code / Codex

Zhiro 的聊天抽屉可以由你装好的 Claude Code 或 Codex 来回答：你在抽屉里说话，Zhiro 在后台拉起它们的命令行，步骤、回答、确认卡都在抽屉里。用的是你自己的 Claude / ChatGPT 订阅额度，不用在 Zhiro 里另配模型服务。模型默认跟随你在它们里面的设置，也可以在设置页的「模型」下拉框里换（列表从你电脑上装的 Claude Code / Codex 读出，只影响 Zhiro）。

## 前提

- Claude Code 或 Codex 已装好并登录（终端里 `claude` / `codex` 能用）。Windows 上 Zhiro 找的是 npm 全局安装的位置；装在别处用环境变量 `ZHIRO_CLAUDE_CLI` / `ZHIRO_CODEX_CLI` 指向可执行文件。
- Zhiro 在跑。

## 步骤

1. Zhiro 窗口 → 配置 → 「AI 用哪家」→ 选 Claude Code 或 Codex。没装的按钮是灰的，悬停能看到原因。
2. 打开抽屉，照常说话：「今天有什么截止的」「关注武汉的控制算法岗」「给第一个准备申请」「打开网申」。
3. 可逆的事它直接做，回答下面有「撤销」；有影响的事出确认卡，点卡上的「确认」。网申只填写，提交由你点。

## 它记不记得上次聊的

记得。Zhiro 存着它的会话编号，每条消息都续接；它自己在磁盘上保存完整对话。「新对话」会丢掉编号。续不上时（它清了旧会话、升级后格式变了）Zhiro 带着之前对话的文字记录重新开始，抽屉里会提示一行。换成另一个 harness 等于新会话，旧记录照样能看，标明是谁答的。

## 要知道的

- 一次只答一条。回答中可以点「停止」。
- 每条消息有时间和花费上限（默认 10 分钟、2 美元估算）；Claude Code 会报估算花费，Codex 不报。改上限在 `config/jobos.yaml` 的 `chat:`（`maxBudgetUsd`、`maxTurns`、`wallMs`、`idleMs`）。
- 它只拿到 Zhiro 的工具和联网搜索，不加载你各家的全局设置、钩子、技能、其他 MCP。
- 它拿的是「这一轮」的临时钥匙：自己点不了确认卡，确认按钮是 Zhiro 的。

## 常见错误

- 「没找到 … 的命令行」：见前提。
- 「上一条还在回答」：等它答完或点停止。
- 「超过时间上限 / 太久没有输出」：这条作废，换个问法；登录过期时会在这里报出来。
- Codex 报模型不可用：在设置页的「模型」下拉框里换一个，或把 Codex 更新到最新版。
